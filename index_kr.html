『MaruMarket』

Jung SangHyeon

프로젝트의 목적 및 가치

Project Goal
직관적이고 안전한
중고거래 시스템 구축

사용자가 안심하고 이용할 수 있는 플랫폼을 목표로,
신뢰성과 사용 편의성을 최우선으로 설계했습니다.

주요기능

  • 회원관리 시스템

    회원가입, 로그인, 프로필 관리

  • 상품관리기능

    상품 등록·수정·삭제를 직관적으로 조작

  • 마이페이지 기능

    판매 상품과 구매 이력 관리

  • 즐겨찾기 기능

    사용자가 관심 있는 상품을 저장

기술 스택: 실무를 가정한 설계

사용 기술선정 이유
BackendJava 17 / Servlet / JSP엔터프라이즈 표준 기술에서의 구현 경험과, Web의 기초 원리에 대한 이해
DatabaseOracle Database상용 DB 설계·운용 스킬 습득과 SQL의 깊은 이해
FrontendJavaScript (jQuery) / HTML5 / CSS3비동기 통신(AJAX) 구현과 반응형 UI/UX 구축
ToolsGit / GitHub / SourceTree팀 개발을 가정한 버전 관리

MVC Pattern
비즈니스 로직과 프레젠테이션 계층을 명확히 분리하고, 유지보수성과 확장성을 높이는 아키텍처를 채택했습니다.

데이터베이스 설계: 무결성을 보장하는 구조

주요 테이블 구성

  • Member: 유저 정보
  • Product: 상품정보와 상태관리
  • File_info: 이미지 파일 데이터
  • Category: 상품 카테고리 관리
  • Product_like: 즐겨찾기 기능 데이터
CASCADE CONSTRAINTS

부모 레코드를 삭제할 때 자식 레코드도 자동으로 삭제해 데이터 불일치(고립 레코드)를 방지.

1:N 이미지 관리

중간 테이블을 활용해 여러 이미지를 자유롭게 관리할 수 있는 구조

코어 기술 구현: 비동기 처리

비동기 기능 (AJAX)

‘즐겨찾기’ 실시간 업데이트

페이지 전환 없이 DB 상태를 갱신하고, UI에 즉시 반영. 사용자의 조작 흐름을 방해하지 않는 부드러운 경험을 제공.

‘더 보기’의 비동기 로딩

초기 표시 데이터 양을 억제하고, 사용자의 요청에 따라 추가 데이터 수집. 서버 부하를 줄이고 표시 속도를 향상.

코어 기술 구현: 파일 관리

다중 이미지 업로드 기능

메인 이미지와 상세 이미지 구분 관리

데이터베이스 설계 수준에서 이미지를 분리 관리(1:N 관계). 썸네일 표시와 상세 표시의 효율적인 데이터 수집 가능.

파일 검증 및 미리보기 기능

업로드 전에 파일 형식과 크기를 검증하고, 불법 파일을 차단. 동시에 미리보기를 표시해 사용자의 게시물 실수를 방지.

향후 확장 계획: 실용성 향상

WebSocket Chat

사용자 간 원활한 커뮤니케이션

페이지 새로고침 없이 메시지를 즉시 송수신

거래 투명성 향상 및 사기 방지

로그 저장 및 관리 기능 구현

양방향 통신 기술 습득

HTTP 통신과의 차이를 이해하고, 적절한 구분을 실천

Usability Upgrade

사용자 친화적이고 간편한 로그인

소셜 로그인으로 회원 가입하는 번거로움을 없애고, 원활한 로그인을 구현

퍼포먼스 개선

데이터베이스 쿼리 최적화

캐싱 전략 도입 (Redis 등)

Vision & Future
